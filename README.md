# 🔐 Java Escape Room Game

A console-based Escape Room game developed in Java where players explore rooms, solve puzzles, collect and use items, and progress toward escaping the game.

## ✨ Features

* 🔑 User signup and login
* 🧩 Multiple rooms and puzzle challenges
* 🎒 Inventory management
* 💡 Hint system
* ❤️ Health and attempt-based gameplay
* 🏆 Score tracking and score history
* 💾 Persistent user and score data using file handling
* 🎨 Interactive console UI with ASCII-style visuals
* 📊 Multiple difficulty levels

## 🛠️ Technologies & Concepts

* Java
* Object-Oriented Programming (OOP)
* Encapsulation
* Inheritance
* Polymorphism
* Collections (`ArrayList`, `List`)
* Exception Handling
* File Handling
* Input Validation
* Regular Expressions

## 🏗️ Main Components

The project is organized around several core components:

* `Player` — manages player state, health, score and inventory
* `Puzzle` — represents puzzle questions, answers, hints and rewards
* `Room` — manages rooms, puzzles and exit requirements
* `Inventory` — handles collected and usable items
* `GameEngine` — controls the main game flow and console interface
* `AuthSystem` — handles signup, login and password-related operations
* `UserStore` — manages persistent user and score data

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Muskanr8/Java-Escape-Room-Game.git
```

### 2. Open the project directory

```bash
cd Java-Escape-Room-Game
```

### 3. Compile

```bash
javac Muskan.java
```

### 4. Run

```bash
java Muskan
```

## 🎮 Gameplay

1. Create an account or log in.
2. Select **Play Game**.
3. Choose a difficulty level.
4. Explore rooms and solve puzzles.
5. Collect and use items when required.
6. Use hints when needed.
7. Manage your health and score.
8. Complete the required challenges and escape.

This project was developed to strengthen practical Java programming skills through an interactive application while applying object-oriented programming, collections, exception handling, file handling and problem-solving concepts.
